--[[
  anxious_btcmining — ox_inventory items
  Copy into ox_inventory/data/items.lua (merge with existing entries).
  Images: add matching .png files to your inventory images folder.

  Item names here must match Config.GpuTiers[x].item / Config.RigModels[x].item
  / Config.Generator[x].item in config.lua exactly -- rename in both places
  together if you want different item keys.

  GPUs are non-stacking (stack = false) so each one's `durability` metadata
  can travel independently between inventory and an installed rig slot.
  They have no client export -- they're installed/removed via the rig's own
  ox_target menu, not "used" directly from the hotbar.
]]
